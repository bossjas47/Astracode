# AstraCode Desktop

แอป Windows ที่เปิดเว็บ AstraCode ตัวจริงในหน้าต่างแอป (แชต ประวัติ ลิมิต เหมือนเว็บทุกอย่าง อัปเดตตามเว็บเอง) และให้เว็บทำงานกับเครื่องนี้ได้:

- **โหมด Code**: ปุ่ม "โฟลเดอร์ในเครื่อง" ผูกโปรเจกต์กับโฟลเดอร์จริง ไฟล์ที่ AI แก้ถูกเขียนลงเครื่อง ไฟล์ที่แก้ด้วยโปรแกรมอื่นซิงก์ขึ้นมาเมื่อกลับมาที่หน้าต่าง `RUN` / Terminal รันใน shell ของเครื่อง
- **แชต**: เครื่องมือ "ใช้คอมเครื่องนี้" ให้ AI ใช้ `LIST` / `READ` / `RUN` / `MCP` และเขียนไฟล์ (`file=`) ในโฟลเดอร์ที่เลือก หน้าเว็บทำตามแล้วส่งผลกลับให้ AI ทำต่อ (สูงสุด 15 รอบต่อคำสั่ง)
- **MCP ในเครื่อง** (Blender ฯลฯ): ตั้งค่าแบบกดเลือกได้จากแชต → ใช้คอมเครื่องนี้ → MCP ในเครื่อง
- แจ้งเตือนเมื่อคำตอบยาวเสร็จตอนสลับไปทำอย่างอื่น · อัปเดตตัวเองจาก GitHub Release

## ความปลอดภัย
- สะพาน (`preload-web.js`) รับคำสั่งเฉพาะหน้าจาก `https://astracode.panderx.xyz` (main ตรวจ origin ทุกครั้ง)
- เว็บอ้างโฟลเดอร์ด้วยชื่อช่อง (`p:<id>` / `chat`) ที่ผู้ใช้เลือกเองผ่านหน้าต่างของ Windows แตะไฟล์นอกโฟลเดอร์ไม่ได้ เลือกทั้งไดรฟ์หรือโฟลเดอร์ผู้ใช้ไม่ได้
- รันคำสั่ง และตั้งค่า MCP (คือโปรแกรมที่จะรันในเครื่อง) ต้องกดอนุญาตในหน้าต่างของ Windows ซึ่งหน้าเว็บกดแทนไม่ได้

## Build
GitHub Actions `desktop.yml` build `.exe` บน Windows เมื่อแก้ไฟล์ใน `desktop/` แล้วอัปขึ้น GitHub Release `desktop-latest` (ตัวติดตั้ง + `latest.yml` สำหรับอัปเดตอัตโนมัติ) ดาวน์โหลดได้ที่ `/download/desktop`
**ต้องเพิ่ม `version` ใน package.json ทุกครั้ง** ไม่งั้นเครื่องผู้ใช้จะไม่อัปเดต

ทดสอบในเครื่อง: `npm install && npm test && npm start`

ยังไม่เซ็นรับรอง: Windows จะเตือนตอนติดตั้ง (More info → Run anyway) จนกว่าจะซื้อ code signing certificate
