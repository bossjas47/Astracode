# AstraCode Desktop

แอป Windows ที่เปิดเว็บ AstraCode ตัวจริงในหน้าต่างแอป (แชต ประวัติ ลิมิต เหมือนเว็บทุกอย่าง อัปเดตตามเว็บเอง) และให้เว็บทำงานกับเครื่องนี้ได้:

- **โหมด Code**: ปุ่ม "โฟลเดอร์ในเครื่อง" ผูกโปรเจกต์กับโฟลเดอร์จริง ไฟล์ที่ AI แก้ถูกเขียนลงเครื่อง ไฟล์ที่แก้ด้วยโปรแกรมอื่นซิงก์ขึ้นมาเมื่อกลับมาที่หน้าต่าง `RUN` / Terminal รันใน shell ของเครื่อง
- **แชต**: เครื่องมือ "ใช้คอมเครื่องนี้" ให้ AI ใช้ `LIST` / `READ` / `RUN` / `MCP` และเขียนไฟล์ (`file=`) ในโฟลเดอร์ที่เลือก หน้าเว็บทำตามแล้วส่งผลกลับให้ AI ทำต่อ (สูงสุด 15 รอบต่อคำสั่ง)
- **MCP ในเครื่อง** (Blender ฯลฯ): ตั้งค่าแบบกดเลือกได้จากแชต → ใช้คอมเครื่องนี้ → MCP ในเครื่อง
- แชตมี `GREP` และแก้บางส่วนของไฟล์ด้วยบล็อก SEARCH/REPLACE · dev server (`npm run dev` ฯลฯ) รันค้างเบื้องหลัง ปุ่ม 🌐 เปิดพรีวิว localhost ในหน้าต่างแยก
- ไฟล์ในโฟลเดอร์ที่แก้ด้วยโปรแกรมอื่นซิงก์ขึ้นทันที (fs.watch) · คำสั่งไม่มี stdin (ไม่ค้างรอ y/n) · Windows ใช้ `chcp 65001` ให้ภาษาไทยไม่เพี้ยน
- ให้ AI ดูหน้าจอ/คุมเมาส์-คีย์บอร์ด (Windows, ปิดไว้ก่อน เปิดด้วยหน้าต่างยืนยัน จนปิดแอป · หยุดทันที Ctrl+Alt+Esc หรือเมนูที่ถาด)
- คลิกขวา คัดลอก/วาง · Ctrl+F ค้นในหน้า · Ctrl+R / ซูม / F11 · จำขนาดหน้าต่าง · หน้าออฟไลน์ลองใหม่เอง · ถาด (ปิดหน้าต่าง = ย่อลงถาด) · เปิดพร้อมเครื่อง · ลิงก์ `astracode://open?path=/code`
- แจ้งเตือนเมื่อแชต/AI ในโหมด Code ทำงานยาวเสร็จ · อัปเดตตัวเองจาก GitHub Release (Mac ต้องเซ็นก่อนถึงอัปเดตเองได้)

## ความปลอดภัย
- สะพาน (`preload-web.js`) รับคำสั่งเฉพาะหน้าจาก `https://astracode.panderx.xyz` (main ตรวจ origin ทุกครั้ง)
- เว็บอ้างโฟลเดอร์ด้วยชื่อช่อง (`p:<id>` / `chat`) ที่ผู้ใช้เลือกเองผ่านหน้าต่างของ Windows แตะไฟล์นอกโฟลเดอร์ไม่ได้ เลือกทั้งไดรฟ์หรือโฟลเดอร์ผู้ใช้ไม่ได้
- รันคำสั่ง และตั้งค่า MCP (คือโปรแกรมที่จะรันในเครื่อง) ต้องกดอนุญาตในหน้าต่างของ Windows ซึ่งหน้าเว็บกดแทนไม่ได้ · เลือก "รันอัตโนมัติ" ต่อโฟลเดอร์ได้ (จำถาวร ปิดได้จากหน้าเว็บ) แต่คำสั่งอันตราย (`isDanger` ใน tools.js: ลบ, force, git push/reset, ระบบ, โหลดสคริปต์มารัน) ยังถามทุกครั้ง

## Build
GitHub Actions `desktop.yml` build Windows `.exe`, Mac `.dmg`, Linux `.AppImage` เมื่อแก้ไฟล์ใน `desktop/` แล้วอัปขึ้น GitHub Release `desktop-latest` (ตัวติดตั้ง + `latest*.yml` สำหรับอัปเดตอัตโนมัติ) ดาวน์โหลดได้ที่ `/download/desktop?os=win|mac|linux`
**ต้องเพิ่ม `version` ใน package.json ทุกครั้ง** ไม่งั้นเครื่องผู้ใช้จะไม่อัปเดต

ทดสอบในเครื่อง: `npm install && npm test && npm start`

ยังไม่เซ็นรับรอง: Windows จะเตือนตอนติดตั้ง (More info → Run anyway) จนกว่าจะซื้อ code signing certificate
