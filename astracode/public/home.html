Kyber (เดิมคือ AstraCode) — AI ทุกตัวในเว็บเดียว ใช้บนมือถือได้

Kyber สร้างโดย Hypatia รวม Claude, ChatGPT, Gemini และ DeepSeek ไว้ในที่เดียว แชตกับ AI เขียนโค้ด สร้างเว็บ และเรียก API ได้จากมือถือ คอมพิวเตอร์ Windows และ Linux จ่ายเป็นเงินบาทผ่าน PromptPay

ทำอะไรได้บ้าง

  • แชต AI หลายโมเดล: Claude, GPT, Gemini, DeepSeek
  • Kyber Code: AI เขียนโค้ด รัน และทดสอบให้เอง เชื่อม GitHub repo ได้
  • Kyber Harness: ให้ AI ทำงานออฟฟิศและงานหลายขั้นตอนแทน
  • Kyber API: API แบบ OpenAI ใช้ key เดียวเรียกทุกโมเดล
  • Kyber Desktop: แอปสำหรับ Windows และ Linux
